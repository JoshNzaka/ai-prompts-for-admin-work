## 📂 Prompt Categories

### 📧 Email & Communication
---

**Summarize an email thread and list action items**
```
Read the email thread below and give me:
1. A 3-sentence summary of what has been discussed
2. A clear list of outstanding action items with owners (if mentioned)
3. Any decisions that have been made

[PASTE EMAIL THREAD HERE]
```

---

**Draft a professional reply declining a meeting request**
```
Draft a polite, professional email declining a meeting request.
- Reason: [e.g. scheduling conflict / executive unavailable]
- Suggest rescheduling: [Yes / No]
- Tone: warm but firm
- Length: 3-4 sentences max

Context: [PASTE ORIGINAL REQUEST HERE]
```

---

**Write a follow-up email after no response**
```
Write a brief, professional follow-up email for a message that received no reply.
- Original ask: [describe what was requested]
- Days since first email: [X]
- Tone: polite, not pushy
- Length: 2-3 sentences
```

---

**Rewrite this email to sound more professional**
```
Rewrite the email below so it sounds polished and professional,
while keeping the same core message. Remove anything vague or casual.
Keep it concise — under 150 words.

[PASTE EMAIL HERE]
```

### 📅 Calendar & Scheduling

**Identify scheduling conflicts across time zones**
```
I'm trying to schedule a meeting with attendees in the following time zones:
- [Person 1]: [City / Time Zone]
- [Person 2]: [City / Time Zone]
- [Person 3]: [City / Time Zone]

Their working hours are roughly 9am–6pm local time.
Suggest 3 possible meeting windows that work for everyone this week.
Today is [DATE].
```

---

**Create a weekly agenda from bullet points**
```
Turn the following bullet points into a clean, structured weekly agenda.
Format it with Day, Time, Item, and Owner columns.
Highlight anything marked as high priority.

[PASTE BULLET POINTS HERE]
```

---

**Prepare a pre-meeting brief for an executive**
```
Write a short pre-meeting brief (max 1 page) for an executive attending the meeting below.
Include:
- Who they're meeting and their role
- The purpose of the meeting
- Key background context
- 2-3 suggested talking points or questions
- Any risks or sensitivities to be aware of

Meeting details: [PASTE DETAILS / NOTES HERE]
```

### ✍️ Documents & Reporting

**Reformat raw notes into a structured report**
```
Turn the rough notes below into a clean, structured report.
Use clear headings, remove redundancy, and write in professional English.
The audience is [senior leadership / a client / internal team].

[PASTE NOTES HERE]
```

---

**Summarize a long document into key points**
```
Summarize the document below into:
1. A 2-sentence executive summary
2. 5 key points in plain language
3. Any recommended next steps

[PASTE DOCUMENT HERE]
```

**Create a structured SOP from a process description**
```
Turn the process description below into a clean Standard Operating Procedure (SOP).
Format it with: Purpose, Scope, Steps (numbered), Responsibilities, and Notes.

[PASTE PROCESS DESCRIPTION HERE]
```

### 🗂️ Operations & Admin

**Build a project tracker outline**
```
I'm managing a project with the following workstreams: [LIST WORKSTREAMS].
Create a simple tracker outline with these columns:
Task, Owner, Due Date, Priority, Status, Blockers, Notes.
Pre-populate with 5 example rows based on the workstreams above.
```

---

**Write an onboarding checklist for a new team member**
```
Create a first-week onboarding checklist for a new [ROLE] joining [COMPANY TYPE].
Include: account setup, key introductions, tools to learn, and meetings to attend.
Format as a checklist they can tick off daily.
```

## 🧠 Tips for Better Prompts

- **Be specific about the audience** — "write for a senior executive" produces different results than "write for a team update"
- **Specify length and format** — AI will default to verbose; tell it exactly how long you want the output
- **Provide context** — the more background you give, the more accurate and useful the output
- **Iterate** — if the first output isn't right, add a follow-up: "Make it shorter", "Use a warmer tone", "Remove the second section"
- **Use role-setting** — starting with "You are an experienced Executive Assistant..." often improves output quality
